2. CUENTABANCARIA
Crea la clase CuentaBancaria con los atributos privados titular y saldo. 

• Constructor con el titular y el saldo inicial. El titular no puede ser nulo ni vacío y el saldo inicial no puede ser negativo. 

• Getters de ambos atributos. saldo no tiene setter: solo cambia con ingresar y retirar. 

• ingresar(double cantidad): la cantidad debe ser mayor que 0. 

• retirar(double cantidad): la cantidad debe ser mayor que 0 y no puede superar el saldo. 
• toString(). 

Clase de prueba: TestCuentaBancaria. Incluye un retiro mayor que el saldo y un ingreso negativo, y muestra el saldo final.
